3. The optimizer says **PV-first, no battery** is optimal for daytime outages but **storage-heavy** for evening outages. Does that match field experience, or are there failure modes our single-node model hides (e.g., genset-start transient reliability)?
4. For EaaS at a Nigerian hospital: is a **fee-vs-savings breakeven financing rate** (4.6%) the right way to present the concessional-capital gap, or is there a standard structure we should model instead?
5. Which **one input** would you verify first before trusting the diesel-avoidance number — genset fuel curve, tariff, or outage pattern? (We have a hypothesis: outage pattern.)
6. Any red flags in bringing a decision-support tool like this to a hospital facilities team (adoption, trust, IT restrictions)?
